Get your workspace connected.

Start with the paired PC and active board. Keep your saved setup while checking the connection or changing a single setting.

Support guide · 6 November 2026

Check your setup

  • A Windows PC running the matching DeskWing companion. The current source targets Windows 10 version 2004/build 19041 or newer, x64.
  • A compatible tablet app. The Android build supports Android 8.0 or newer with a current system WebView. iOS signing, beta distribution, and physical iPad/Pencil testing are being prepared.
  • For Wi-Fi, both devices on the same reachable local network. A guest network or client-isolation setting can block the connection.
  • For Android USB, a data-capable cable, authorized USB debugging, and the companion's USB helper. The first iOS host does not implement Android's ADB USB workflow.
  • For OBS or Soundpad, that application must be installed/configured on the Windows PC. DeskWing does not include those applications or a sound collection.

Second display additionally needs a compatible virtual-display driver already installed on the PC, a separate extended desktop, and explicit sharing. DeskWing does not silently install a driver. Handwriting depends on your keyboard/IME or Apple Pencil/Scribble configuration; ordinary typing remains available.

Make the first connection

  1. Open the Windows companion and choose Tablet connections. Keep the companion running.
  2. On the tablet, choose Pair tablet and the supported Wi-Fi or USB connection.
  3. Compare the certificate code with the code shown on your PC. Enter the current pairing PIN. Never approve a different PC certificate just to clear an error.
  4. Check the connected PC and active board. Open Stream Studio for your board, or choose the writing, pen, or display workspace you need.

On supported Android builds, Scan pairing QR is an optional alternative that requests camera access. Denying it still allows manual pairing.

If Windows Firewall asks about the companion, use the network scope appropriate to your trusted setup. Setup and version-specific instructions are in the project guide.

A page or button is missing

First confirm the connected PC and active profile. A different saved board can have different pages; that does not mean your sound library or original board has been deleted. On narrow layouts, also check for horizontally scrollable page tabs.

On the PC, inspect the board editor and profile list. Keep a backup before editing. Add or restore the particular page you need; avoid importing an unrelated whole board over your current pages. Developer/test instances can use a separate data directory, so compare the actual running companion rather than copying a development configuration into place.

For a live Memes page, choose Live Soundpad library as that page's source. Keep Soundpad running and its desired library loaded. A live page follows the library; manually saved buttons and live library entries are different sources.

Sound buttons are visible but silent

  1. Check the page's Soundpad output: Speakers, Microphone, or Both. Microphone-only output may reach a voice app without playing through local speakers.
  2. Confirm Soundpad is running on the PC and the selected sound is available. Missing or duplicate file identities can make a particular entry unavailable.
  3. Read the action's success/error feedback. Do not repeatedly tap an action that reports an ambiguous lost confirmation; it may already have run.
  4. Check Soundpad's playback device and the receiving application's microphone selection/volume. DeskWing cannot guarantee the receiving voice app's routing.

Use an explicit output test only when you are ready for audible playback. Do not share private sound files or an entire library when reporting a routing problem.

Display or pen viewing needs attention

Start fails
Check that the PC has created its extra monitor, enabled sharing, and is using a source refresh rate sufficient for your requested target. Check any reported decoder or format limit.
The picture is still
An unchanged desktop is deliberately shown as Still image. Move content on the shared monitor to assess video delivery. Target Hz, received frames, and decoder-rendered estimates are different measurements.
Video is below the selected target
Resolution, capture/encoding load, Wi-Fi throughput, tablet power state, and decoder support can reduce delivery. Start with a smaller display and 60 Hz, or use the quality options your build offers.
Pen input does not reach Windows
Check the separate PC input permission, selected target, current geometry, foreground/focus requirements, and app privileges. Pressure and tilt behavior also depend on the receiving Windows app and brush.
Backgrounding or sharing is revoked
The session stops and its picture/input are cleared. Return to the app and explicitly start a new session. Old input is not automatically replayed.

The available input/video combination depends on the installed build. Check its release notes before assuming that a viewing session also forwards touch or pen.

Report a reproducible problem

DeskWing is developed by Tuğcan Topaloğlu. Email tugcan@tugcan.dev for private support, or open a DeskWing GitHub issue for a general technical problem. Include the app/companion versions, tablet/OS model, connection type, workspace, exact redacted error, and short steps to reproduce. Explain what you expected and what happened.

GitHub issues are public. Remove PINs, tokens, private keys, passwords, personal paths, document content, and unreviewed logs or screenshots before posting. Send only what is needed, including when contacting support by email.

For local data-removal guidance, read Retention, unpairing, and deletion. No remote cloud account is required for the core DeskWing pairing workflow.
